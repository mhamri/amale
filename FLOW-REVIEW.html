Assertions checked retained constraints, the global/task/dependency decisions, dependency references, exclusion of unrelated routes and intact original decision history. General unscoped decisions are deliberately retained, so this does not claim constant-size context for every possible project.

What we declined to “optimize”

A prototype that kept only the five newest decisions was smaller, but did not prove it preserved important earlier constraints. It was not adopted. Filesystem loss is an infrastructure problem, so quarantine preserves the existing repair count and model depth. It does not force Kimi escalation merely because a checkout moved.

Capability limits remain explicit

The host still performs discovery, workspace preparation, actual integration and semantic acceptance. The skill is not a background daemon, model-quality benchmark or native compaction replacement. Restoring a moved workspace requires reconciliation and fresh evidence; the runtime does not guess where files moved. This round used deterministic fixtures and native-agent critique, not fabricated Jev or cross-family review receipts. Earlier formal audit acceptance remains separate.
