Where concurrency stops

Checks within the same task remain serialized because arbitrary build/test commands may mutate shared generated files. Integration writes and feature-wide integration checks remain host-controlled serial work. Native external reviews recorded afterward through review cannot be tracked while they execute; the lease covers the runtime's reviewer and task check commands.

The host still drives dispatch; this change does not install a background scheduler. Suggested batches include the focus when eligible—dispatch each operation once. Independent tasks may advance as soon as their own evidence and prerequisites pass, without a whole-batch barrier.
