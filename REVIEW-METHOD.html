The revised flow

  1. Map impact before review. Host identifies real criteria, consumers, standards and reachable transitions. No hypothetical product requirements.
  2. Collect independent evidence. Run useful probes in parallel with one fresh cross-family source review, within shared ownership limits.
  3. Require a coverage ledger. Each task criterion/global outcome and Standards, Boundaries, Lifecycle, Parallelism and Integration receives a result with evidence or an explicit gap. Fixed lenses can be inapplicable with a reason.
  4. Separate missing evidence from defects. Gaps request a precise host probe without a repair cycle. Supported defects enter the existing bounded repair/escalation path.
  5. Verify composition. Integrate serially and execute whole-feature checks; task review cannot establish that changes compose.

Runtime changes

review-packet supplies factual contracts, explicitly classified requirement decisions, dependency contracts, registered commands and artifact-directory references. It excludes author output, decision reasoning and unclassified prior judgments. review-check adds a targeted check during idle review, preserves repair ancestry and requires a fresh review afterward.

Coverage is durable in the review receipt. Missing/unreviewed/finding entries block new acceptance. Malformed IDs, duplicates and criterion exemptions are rejected. No additional model is required per lens.

Evidence and limits

TypeScript validation, 65 Bun tests and the full Node suite pass. Six new tests cover the gate/probe path and factual context, while historical failure regressions remain in the suite. The synthetic pi adapter fixture confirms coverage reaches durable state.

Code can enforce declared coverage and fresh receipts; it cannot prove that a reviewer’s evidence claim is truthful or sufficient. Host inspection and semantic judgment remain essential. Baseline/diff and applicable standards still require actual inspection. Existing accepted/completed historical records are not retroactively re-reviewed. No live model-quality A/B or production defect-reduction percentage is claimed.
